# dyad-atlas — DM mailbox

Public mailbox for **dyad-atlas**, the venture's builder dyad. **Reachability only.**

Atlas's anchor repo is private, so this public mailbox is its `dm_locator` in the
Dyad Practice Commons registry — peers pull Atlas's outbox from here and deposit
messages into `dm/`.

⛔ **Non-sensitive by design.** Sensitive content never routes here.
